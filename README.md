# Threat Model Evaluation Tool (TMEval)

TMEval is a modular Python application designed to compare threat models generated by Large Language Models (LLMs) against a ground truth, using multiple evaluation strategies. It leverages LLMs such as Claude, ChatGPT, and Gemini for subjective, dimension-based evaluation (LLM-as-a-judge), as well as BLEU and ROUGE for lexical similarity, and BERTScore for semantic similarity assessment.

At the moment, it is configured to work with the threat model format generated by [STRIDE GPT](https://github.com/mrwadams/stride-gpt), a tool that focuses on using LLMs to generate threat models based on application description provided by the user.

## Quick Start

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

2. **Set up API keys** in a `.env` file:
   ```
   CLAUDE_API_KEY=your_claude_api_key
   OPENAI_API_KEY=your_openai_api_key
   GEMINI_API_KEY=your_gemini_api_key
   ```

3. **Configure file pairs** in `config.yaml`:
   ```yaml
   files:
     - reference_file: "input/references/dos.txt"
       input_file: "input/inputs/dos.txt"
       title: "Denial of Service"
       description: "Denial of Service Threats"
   ```

4. Use the Dependency Installer
```bash
python install_dependencies.py
```

5. **Run the evaluation**:
   ```bash
   python main.py
   ```

6. **Check results** in the `results/` directory. It also launches a simple dashboard in the browser on port 8050.

## Application Details

### Purpose

TMEval provides multiple ways to compare the threat models:

#### Dimension-based Evaluation (LLM-as-a-Judge)
This is inpired on [G-EVAL](https://arxiv.org/pdf/2303.16634) and uses an LLM to evaluate different dimensions of the generated input against a reference.

Each dimension is implemented by a specific prompt (see `prompts` folder). It currently has the following dimensions:

- **Plausibility**: Do the listed threats technically align with the inferred system characteristics from the reference?
- **Consistency**: Do the listed threats align with the reference, without unsupported or contradictory information?
- **Coverage**: Vary from STRIDE category to STRIDE category. In general, each one includes the following three dimensions:
  - **Targets Coverage**: Are the same targets identified as affected?
  - **Weaknesses Coverage**: Are similar vulnerabilities or exposures highlighted?
  - **Attacks Coverage**: Are comparable attack methods or strategies described?

#### LLM-based BERTScore Evaluation
- Uses an LLM to assess semantic similarity between reference and input threats
- Provides precision, recall, and F1 scores similar to traditional BERTScore
- Leverages the LLM's understanding of semantic meaning rather than token embeddings

#### BLEU and ROUGE

More traditional BLEU and ROUGE metrics evaluators are also included.

## Configuration Options

TMEval is configured through `config.yaml`:

### Multiple Evaluators Configuration

```yaml
# Evaluator configuration with multiple evaluator types
evaluator:
  types: 
    - "dimension"  # LLM-based dimension evaluation
    - "bertscore"  # LLM-based semantic similarity evaluation
  
  # BERTScore-specific configuration
  bertscore:
    implementation: "llm"  # Uses LLM instead of traditional BERTScore
```

### LLM Configuration

```yaml
# Available LLM configurations
llms:
  claude:
    api_key: ${CLAUDE_API_KEY}
    model: "claude-3-opus-20240229"
    api_url: "https://api.anthropic.com/v1/messages"
    num_completions: 3  # Generate 3 completions per prompt
  # Other LLMs...

# Specify which LLM to use (must match one of the keys in the llms section)
active_llm: "claude"
```

### Evaluation Dimensions (for dimension-based evaluator)

```yaml
dimensions:
  # Common dimensions
  consistency:
    prompt_file: "prompts/consistency.txt"
    category: All
    weight: 0.30

  plausibility:
    prompt_file: "prompts/plausibility.txt"
    category: All
    weight: 0.10
    # Other dimensions...
```

### Output Settings

```yaml
output:
  format: "json"
  directory: "results"
  filename_template: "{input_filename}_eval.json"
```
