# Threat Model Evaluation Tool (TMEval)

TMEval (Threat Model Evaluation) is a modular Python tool designed to compare STRIDE threat models generated by Large Language Models (LLMs) against a ground truth, using multiple evaluation strategies, including a dimension-based evaluation where either the same or a different LLM that generated the threat model serves as the judge (LLM-as-a-judge), as well as BLEU and ROUGE for lexical similarity, and BERTScore for assessing semantic similarity. The focus is on LLM-as-a-Judge, given its superior performance.

At the moment, it is configured to work with the threat model format generated by [STRIDE GPT](https://github.com/mrwadams/stride-gpt), a tool that focuses on using LLMs to generate threat models based on an application description and other information provided by the user.

## Quick Start

1. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

   To learn more about the installation process, consult [README-installation.md](README-installation.md).

   In addition, if you want to view the dashboards, install the following dependencies:
  
    ```bash
   pip install dash nltk
   pip install dash-bootstrap-components
   ```

2. **Set up API keys** in a `.env` file:
   ```
   CLAUDE_API_KEY=your_claude_api_key
   OPENAI_API_KEY=your_openai_api_key
   GEMINI_API_KEY=your_gemini_api_key
   ```

3. **Configure file pairs** in `config.yaml`:
   ```yaml
   # Input file pairs and metadata
   files:
      - reference_file: "input/references/spoofing.txt"
      input_file: "input/inputs/spoofing.txt"
      title: "Spoofing"
      description: "Table of Spoofing Threats"
      # ... for each STRIDE category
   ```
   Update those files with the ground truth threats (in the STRIDE GPT format — example files already follow this format as a guide) that will be used for comparison. The `input/inputs/*` directory also needs to be updated with the STRIDE GPT output, after which the evaluation can be run ([Application Details](#application-details)).

4. Use the Dependency Installer
    ```bash
    python install_dependencies.py
    ```

## Application Details

### Purpose

TMEval provides multiple ways to compare the threat models:

#### Dimension-based Evaluation (LLM-as-a-Judge)
This is inpired on [G-EVAL](https://arxiv.org/pdf/2303.16634) and uses an LLM to evaluate different dimensions of the generated input against a reference.

Each dimension is implemented by a specific prompt (see `prompts` folder). It currently has the following dimensions:

- **Plausibility**: Do the listed threats technically align with the inferred system characteristics from the reference?
- **Consistency**: Do the listed threats align with the reference, without unsupported or contradictory information?
- **Coverage**: Vary from STRIDE category to STRIDE category. In general, each one includes the following three dimensions:
  - **Targets Coverage**: Are the same targets identified as affected?
  - **Weaknesses Coverage**: Are similar vulnerabilities or exposures highlighted?
  - **Attacks Coverage**: Are comparable attack methods or strategies described?

#### LLM-based BERTScore Evaluation
- Uses an LLM to assess semantic similarity between reference and input threats
- Provides precision, recall, and F1 scores similar to traditional BERTScore
- Leverages the LLM's understanding of semantic meaning rather than token embeddings

#### BLEU and ROUGE

More traditional BLEU and ROUGE metrics evaluators are also included.
